# Simple Interest Calculator

A simple Bash script that calculates simple interest given the principal amount, annual rate of interest, and time period.

## Project Description

This project is part of the IBM Introduction to Git and GitHub final assessment.

The script calculates simple interest using the formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

* Takes user input.
* Calculates simple interest.
* Displays the result.
